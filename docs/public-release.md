# 公开版本与数据边界

本项目沿用原仓库的 GPLv3 许可证。2026-09-07 的创作者工作台改造包括本地导入、平台预览、草稿准备、人工核对入口和结果恢复。

原有平台适配器与同步能力来自 [Wechatsync 公开上游](https://github.com/wechatsync/Wechatsync)，沿用其适用许可证和源码声明；本仓库的工作台改造不改变第三方平台名称与图标的权利归属。

公开的是源码，不是带登录账号的在线服务。默认服务只监听本机回环地址；不要将本机端口、Cookie、浏览器调试端口直接暴露给公网。

## 公开版与本机可选能力

小红书原有自动化适配器未随项目开源。安装或构建时，若没有该可选实现，脚本会生成明确的手工入口，不读取凭据、上传图片或创建草稿。已有本机实现和符号链接不会被覆盖。只有在拥有合法使用和分发权时才自行安装可选实现；本项目不提供私有实现或下载链接。

因此公开版的小红书是手工模式，不能将本机安装私有模块后的测试结果写成公开版能力。公开版测试会跳过该可选模块专属用例，并运行公开手工入口的零操作测试。

飞书导入需要用户自己的 `lark-cli` user 认证。可设置 `PUBLISHER_LARK_CLI` 为本机原生 CLI 路径、`PUBLISHER_FEISHU_PROFILE` 为已配置的个人 profile；导出始终使用 `--as user`。默认保留历史别名 `misshe-personal` 以兼容已有本机配置，此名称不是账号或凭据。企业只读身份仍不可用于写入或绕过权限。

选题分析需要本机 Codex CLI；网络来源、平台登录和账号额度各自独立。没有来源、权限或模型时明确报告，不用虚构选题和成功结果填充。

## 不随仓库公开的资料

- Cookie、令牌、`.env`、浏览器用户目录和登录会话。
- SQLite 数据库、用户文章、飞书导出包、配图与发布快照。
- 私人文档链接、实际验收稿与运行截图。
- 私有适配器实现，以及本机生成的构建和导出文件。

不要通过强制加入忽略文件、上传数据库或打包整个本机目录来发布项目。

## 发表策略

工作台只提供草稿同步、编辑器准备和本地导出。最终发表、提交审核和通知粉丝由用户到平台确认。工作台 HTTP 接口不会自动公开发表，旧的 `direct` 请求也应在任何远程副作用前被拒绝。

公众号发表后修改机会与范围有限；不群发通知也不等于保存草稿。规则来源：

- [腾讯客服：修改已群发消息](https://kf.qq.com/faq/180206QBjaU7180206ammUni.html)
- [腾讯客服：发表与群发通知](https://kf.qq.com/faq/230913IjEVNN2309136nUZNZ.html)

底层 CLI 保留部分历史兼容参数，不代表各平台已实现可信的自动公开发布。公开使用优先采用默认草稿模式；没有可靠回执的结果必须核对后再操作。
