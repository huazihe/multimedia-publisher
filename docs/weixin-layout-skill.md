# 公众号排版 Skill｜维护手册

> 文档用途：说明公众号文章排版 Skill 的边界、使用方法、模板目录、验收方式和新增模板规则。
> 
> 当前维护源：`skills/weixin-layout/`
> 
> 最近盘点：2026-07-26

## 1. 这个 Skill 负责什么

公众号排版 Skill 负责把已经准备好的文章标题、正文、导语和图片清单，套入本地公众号 HTML 模板，产出可以交给公众号发布链路的排版 HTML。

它只负责文章结构、模板选择和 HTML 产物，不负责登录、不读取登录 Cookie、不直接调用公众号发布接口。发布动作由后续的发布链路负责。

## 2. 快速使用

在项目根目录执行：

```bash
# 随机选择一套模板
python3 skills/weixin-layout/scripts/pick_layout.py --json

# 查看全部模板
python3 skills/weixin-layout/scripts/pick_layout.py --list

# 使用固定种子复现模板选择结果
python3 skills/weixin-layout/scripts/pick_layout.py --json --seed 20260722

# 指定模板
python3 skills/weixin-layout/scripts/pick_layout.py --json \
  --template "工业质检·清爽绿白.html"
```

脚本返回的 `path` 是本次实际选中的模板路径。后续处理必须使用这个路径，不要自行拼接另一份模板。

## 3. 输入约定

开始排版前，至少要准备：

| 输入 | 要求 |
| --- | --- |
| 文章标题 | 最终标题，不使用模板示例标题 |
| 正文 | 完整正文，并保留标题层级和自然段 |
| 导语 | 建议 50–100 字，用于首屏引导 |
| 公众号名称 | 默认：维视智造 |
| 公众号简介 | 默认：专注机器视觉、工业检测与智能制造解决方案 |
| 图片清单 | 只使用用户提供或已确认的真实图片 |

没有真实图片时，保留明确的图片缺口说明；不要生成客户现场、检测效果或产品图片来填空。

## 4. 标准处理流程

1. 使用 `pick_layout.py` 选择模板；用户指定风格时使用 `--template`，否则优先随机选择。
2. 读取脚本返回的模板 `path`，理解模板已有的结构和 class。
3. 只替换模板中的标题、栏目、导语、正文、公众号信息和图片位。
4. 保留模板原有 CSS 和 class，不另起一套主题。
5. 删除模板说明、示例句和占位提示，不残留“此处为……”或“替换为……”等文本。
6. 将成品写入：`publisher-dashboard/data/drafts/wechat-layout/YYYY-MM-DD-slug.html`。
7. 运行静态检查，再用浏览器抽查桌面宽度和移动宽度。
8. 最终只把 HTML 交给发布链路，不在本 Skill 内登录或发布。

## 5. 当前目录结构

```text
skills/weixin-layout/
├── SKILL.md                         # Skill 行为规范与边界
├── agents/openai.yaml                # Skill 在 Agent 目录中的显示信息
├── references/外部公众号样式库.md      # 只记录抽象样式，不保存外部全文和品牌素材
├── scripts/pick_layout.py            # 随机或指定模板
├── scripts/check_layout.py           # HTML 静态验收
└── templates/                        # 公众号 HTML 模板库
```

当前模板库共 40 套，包含工业质检、专业案例、工程笔记、白皮书、杂志分栏、暖色阅读、青瓷清雅等方向。模板文件名本身就是风格索引，新增模板时要保持名称可读、可检索。

## 6. HTML 验收

完成 HTML 后执行：

```bash
python3 skills/weixin-layout/scripts/check_layout.py \
  /absolute/path/to/final.html
```

检查必须通过：

- HTML 基本结构完整；
- 没有模板占位符；
- 没有 `/Users/`、`/home/` 或 Windows 本机绝对路径；
- 图片引用可追溯；
- 图片未确认时不伪造图片。

浏览器抽查至少包括：首屏标题、第一段正文、正文最密集段落、图片区域和移动宽度。出现溢出、字号过小、占位符或图片缺失时，回到源 HTML 修复后重新检查。

## 7. 新增模板规则

只有用户明确要求“把这个风格做成模板”时，才新增模板。外部文章只记录抽象样式，不复制原文、完整 CSS、图片、二维码、作者信息或品牌标识。

新增模板必须：

1. 放入 `skills/weixin-layout/templates/`；
2. 至少包含以下占位内容：文章主标题、栏目/副标题、导语、正文、公众号名称、公众号简介；
3. 复用模板自身的结构和 class，不依赖本机绝对路径；
4. 能被 `pick_layout.py --list` 发现；
5. 用一个最小示例文章完成 `check_layout.py` 验收；
6. 在下方变更记录中登记模板名、用途和验收日期。

新增模板登记卡：

```text
模板名称：
文件名：
适用内容：案例 / 行业趋势 / 技术干货 / 活动报道 / 其他
主色与辅色：
标题与正文层级：
图片布局：
来源与授权边界：
验收命令：
验收日期：
备注：
```

## 8. 维护规则

- 修改 Skill 行为时，优先修改 `SKILL.md`，再同步更新本维护手册。
- 修改模板时，只改对应模板文件，不把通用规则散落到多个模板里。
- 修改脚本参数时，同步更新“快速使用”和“标准处理流程”。
- 新增模板、删除模板或改变默认公众号信息时，必须写入变更记录。
- 发布前不得把 Cookie、浏览器 profile、session 文件、数据库或任何登录凭证放进 Skill 包。
- Skill 包只包含排版规则、脚本、参考说明和模板，不包含运行时数据。
