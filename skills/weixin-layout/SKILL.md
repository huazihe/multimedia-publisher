# 微信公众号文章排版

这个 Skill 将文章正文填入项目内的公众号模板，生成可交给微信公众号发布链路的 HTML。模板库位于本 Skill 的 `templates/`，不要把模板路径写死到另一台机器的 `/home/node` 或其他用户目录。

## 边界

- 只做文章结构、模板和 HTML 产物；不检查登录态，不调用发布接口，不把文件直接发到公众号。
- 必须优先使用 `scripts/pick_layout.py` 的随机结果。用户明确指定模板时才使用 `--template`。
- 不新写一套 CSS 主题。需要微调时，复用所选模板已有的结构和 class。
- 如果正文、标题或图片使用清单缺失，先补齐输入；不要用模板示例文字假装成用户内容。
- 图片只能使用用户给出的图片使用清单中的资源；没有真实图片时保留清晰的图片缺口说明，不生成客户现场或检测效果的假图。

## 输入与默认值

需要：文章标题、正文，以及可选的副标题/栏目、导语、公众号名称、公众号简介和图片使用清单。

默认公众号信息：

- 名称：维视智造
- 简介：专注机器视觉、工业检测与智能制造解决方案
- 栏目：维视智造

## 操作流程

### 1. 选择模板

在当前 Skill 目录执行：

```bash
python3 scripts/pick_layout.py --json
```

脚本返回模板文件名、绝对路径和文件大小。必须读取返回的 `path`，不能自行拼接另一份模板路径。查看全部模板：

```bash
python3 scripts/pick_layout.py --list
```

需要可重复验收时使用固定种子：

```bash
python3 scripts/pick_layout.py --json --seed 20260722
```

### 2. 填充文章

读取选中的 HTML 后，替换模板示例内容：

| 模板内容 | 替换为 |
| --- | --- |
| `此处为文章主标题`、`文章主标题` | 用户提供的标题 |
| `副标题或栏目名称`、`副标题或英文标题` | 副标题；没有则使用默认栏目 |
| `此处为引导语`、`导读` | 文章摘要或开头导语，建议 50–100 字 |
| `此处为正文`、`正文区域`、示例正文段落 | 用户完整正文 |
| `此处放公众号名称`、模板中的公众号名 | 公众号名称 |
| `此处放公众号简介` | 公众号简介 |
| `配图位`、`替换为实际图片` | 图片清单中的实际图片和图注；没有图片则删除该图片位 |

正文规则：保留原意和标题层级；长段落按自然段拆分；小标题承接模板已有 H2/H3 结构；删除全部模板说明、示例句和占位提示。不要残留“此处为……”或“替换为……”等文字。

### 3. 输出与验收

推荐把最终文件写入项目工作区，例如：

```text
publisher-dashboard/data/drafts/wechat-layout/YYYY-MM-DD-slug.html
```

完成前运行：

```bash
python3 scripts/check_layout.py /absolute/path/to/final.html
```

检查必须通过：HTML 基本结构完整、无明显模板占位符、无本机绝对资源路径、图片引用可追溯。然后用本地浏览器打开 HTML，抽查标题、首屏、最密集正文段、图片和移动宽度；发现溢出或占位符后回到源 HTML 修复并重测。

最终回复说明：模板文件名、最终 HTML 绝对路径、图片使用/缺口报告、静态检查结果，以及“尚未发布”。需要进入公众号草稿时，再把 HTML 交给独立的发布流程。

## 模板沉淀

当用户提供外部公众号并说“以后参考这种排版”时，只记录抽象样式信息（颜色、字号、行高、层级、图片布局和分隔方式）到 `references/外部公众号样式库.md`。不要复制外部文章全文、完整 CSS、图片、二维码或品牌标识。只有用户明确要求新增模板时，才在 `templates/` 新建模板，并用本 Skill 的占位规则验证。
