# 外部公众号样式库

本文件用于记录用户喜欢的外部公众号排版风格。这里只保存“抽象样式档案”，不保存外部文章正文、完整 HTML、完整 CSS 或原图。

## 使用边界

- 只借鉴版式规律：色彩、字号、行高、分隔方式、小标题样式、卡片结构、段落节奏。
- 不复制外部公众号的完整模板、原文、图片、品牌元素、二维码、作者信息。
- 外部样式必须改造成维视智造可用模板，保留维视公众号名称、简介、栏目和内容结构。
- 用户只说“这篇排版好看”时，先保存样式档案，不立即替换默认模板库。
- 用户明确说“以后就用这个风格”或“把这个变成模板”时，才生成本地模板。

## 样式档案记录格式

```markdown
## {style_id}｜{样式名称}

- 来源链接：
- 抓取时间：
- 原公众号：
- 原文标题：
- 用户评价：
- 适用内容：案例文章/行业趋势/技术干货/活动报道/其他
- 主色：
- 辅色：
- 字号：
- 行高：
- 段落结构：
- 小标题结构：
- 图片布局：
- 分隔符/引用块：
- 不可复制元素：
- 转模板状态：未转模板/已转模板
- 本地模板文件：
```

## 转成本地模板时

模板放到：

```text
skills/公众号排版样式/templates/
```

命名建议：

```text
imported_{YYYYMMDD}_{短slug}.html
```

模板必须使用占位符：

- `此处为文章主标题`
- `副标题或栏目名称`
- `此处为引导语`
- `此处为正文`
- `此处放公众号名称`
- `此处放公众号简介`

完成后必须确认 `pick_layout.py` 能随机选到该模板。
